# ML Wine Quality Dashboard

## Описание проекта
Веб-приложение (дашборд) для инференса моделей машинного обучения и визуального анализа набора данных о качестве вина. Проект разработан в рамках расчетно-графической работы по дисциплине "Машинное обучение и большие данные".

Приложение позволяет загружать новые данные или вводить их вручную, получать прогнозы от шести различных ML-моделей, а также изучать статистические зависимости в исходном датасете.

## Стек технологий
- Python 3.10+
- Streamlit (веб-фреймворк)
- Scikit-learn (Ridge, Gradient Boosting, Bagging, Stacking)
- CatBoost (CatBoostRegressor)
- TensorFlow / Keras (Fully Connected Neural Network)
- Pandas, NumPy (обработка данных)
- Matplotlib, Seaborn (визуализация)
- Joblib / Pickle (сериализация моделей)

## Используемые модели
1. **Ridge Regression** — линейная модель с L2-регуляризацией
2. **Gradient Boosting** — ансамблевая модель на основе деревьев
3. **CatBoost** — градиентный бустинг с обработкой категориальных признаков
4. **Bagging Regressor** — ансамбль на основе бэггинга
5. **Stacking Regressor** — двухуровневый ансамбль (мета-модель + базовые алгоритмы)
6. **FCNN (TensorFlow)** — глубокая полносвязная нейронная сеть

Все модели оценивались по метрике `R²` на тестовой выборке и отобраны в процессе выполнения лабораторных работ.

## Запуск локально
1. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate     # Windows
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   streamlit run app.py
   ```
